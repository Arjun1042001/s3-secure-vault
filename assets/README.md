# Project Images

Only redacted project images should be added to this directory.

Suggested filenames:

- `s3-properties.png`
- `s3-permissions.png`
- `s3-versioning.png`
- `s3-lifecycle.png`

Before publishing an image, hide the AWS account number, user name, root-user indicator, email address, and any bucket name containing the account number. Never publish access keys, tokens, or other credentials.
