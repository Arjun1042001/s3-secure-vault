# assets

Add only redacted screenshots to this directory.

Recommended evidence:

- `bucket-properties-redacted.png`
- `permissions-redacted.png`
- `object-versions-redacted.png`
- `lifecycle-rule-redacted.png`

Before publishing a screenshot, hide:

- AWS account number
- User name and root-user indicator
- Bucket name if it contains the account number
- Email address
- Access keys, tokens, ARNs, or other private identifiers

The original screenshots are intentionally excluded from GitHub.
